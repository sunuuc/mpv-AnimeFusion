# 在线字幕

播放器通过 .NET `HttpClient` 直接请求 [ASSRT](https://assrt.net/api/doc)、[ameNZB](https://amenzb.moe/) 和 [TsukiHime](https://tsukihime.org/)，不经过项目服务器，也不调用 PowerShell 下载字幕。

## 来源

来源设置提供三个独立开关，默认全部开启，选择保存在本机。关闭来源后立即取消正在进行的搜索，从搜索来源选项中隐藏该来源；再次手动搜索时，“全部”只请求已开启的来源。重新开启不会自动搜索。已下载字幕仍可从本地使用，关闭 ASSRT 不清除 API 密钥。ameNZB 与 TsukiHime 在设置及搜索选项中标注“（测试）”。

- ASSRT 使用官方字幕 API，保留字幕组提供的原始整包。
- TsukiHime 使用 `https://api.tsukihime.org/v1` 的搜索和条目详情接口，按输入框关键词检索，从已提取的字幕附件取得独立字幕，不下载视频或使用种子客户端。
- ameNZB 按输入词访问公开网站的 `/browse?q=…&page=…`，所选语言通过 `sub_lang` 发送；简繁均请求 `zh`，再按实际附件区分，英语和日语分别请求 `en` 和 `ja`。全部语言不带此参数。不调用作品联想接口，也不将没有集数的搜索限定为电影。发布列表的语言标签不代表已有独立字幕，因此搜索时继续读取候选版本的详情，只将该版本实际提供的完整文字字幕加入结果。语言、简繁、格式和下载地址均来自真实附件，不把聚合表中的其他版本挂在当前版本下。保留网站匹配到的外文标题；每页一次列表请求，详情中的可用字幕按实际发布编号缓存，同一编号随后出现在列表中且已有所选语言时直接复用，未找到该语言仍读取其自身详情。“全部语言”读取自身详情以免遗漏其他语言，沿用至少一秒的请求间隔。每确认一项便显示，不等待整页的详情全部完成。点击时复用已核实的资料，直接下载字幕。其公开 Newznab API 面向发布资源，目前未发现可用于字幕搜索和下载的官方 API 文档，因此网站入口变动可能影响这一来源。

ameNZB 和 TsukiHime 的字幕以单集提取轨道为主，不能将某一集的多语言附件当作整季字幕包。搜索结果直接区分语言，点击所需版本即可下载并尝试对应当前集，不再进入逐文件选择页；不会为了凑成整季而自动遍历下载其他集。已经下载的字幕继续进入同一个本地字幕库。

ameNZB 根据真实轨道名称区分简繁，未确认简繁时显示“中文”；实际存在但语言未知的字幕显示“其他”。没有附件、只有图片字幕、强制片段或招牌歌词轨的发布项不生成可点击字幕。分页位置依据原始发布列表，不因一页没有可用字幕而提前结束。一次搜索内缓存已核实详情和列表页，暂停后只重试未完成的请求；主动重新搜索创建新的查询会话并重新核实，不复用旧的可用性判断。

ameNZB 的公开 `/browse` 不支持独立的季集查询参数。手动选择季集时，输入框显示 `S04E02` 等标准后缀，搜索请求原样发送可见关键词；再用列表已有的季集资料排除不相关发布，避免逐条核验其他集。仍需读取列表分页，不发送该入口忽略的 `season`、`ep` 参数；选择“全部”时移除相应后缀与限制。

网站的发布总数与播放器已确认可下载的语言字幕条数不同。详情省略发布标题的附加别名时，按现有标题解析结果核对；明确写出的季集优先于网站目录坐标。多集范围或无法确定单集的冲突条目仍可下载，保存到“未分类”而不自动加载。不会根据异常季度标签猜测绝对集数与季度集数的换算。

## 服务凭据

登录 [ASSRT 用户面板](https://secure.assrt.net/usercp.php)获取个人 API 密钥。开启 ASSRT 后显示“获取密钥”、输入框和“验证”；验证成功即保存，失败不覆盖原凭据。关闭 ASSRT 时隐藏密钥区域并取消验证。请求使用 `Authorization: Bearer`，密钥不会出现在下载地址或日志中。

密钥通过 Windows 当前用户的 DPAPI 加密，保存在 `%LOCALAPPDATA%/mpv-AnimeFusion/Subtitles/account.bin`。个人账号文件及已下载字幕不进入源码或发行包，程序不附带项目应用密钥。

ameNZB 和 TsukiHime 的字幕入口无需 API 密钥；未设置 ASSRT 密钥时仍可搜索这两个来源及使用本地字幕。

## 搜索与筛选

别名下拉列表先显示已取得的名称，联网失败时保留这些名称并显示失败提示。作品资料与英文名称补充分别缓存，补充失败后再次点击只重试失败部分；不把网络错误保存成“没有别名”。同一窗口共享仍在进行的请求。

ameNZB 与 TsukiHime 暂不显示片源时长，不为时长逐条追加媒体资料请求。

- 打开窗口及保存来源设置均不自动搜索；输入、删字或修改关键词只改变输入内容，保留已有结果。来源、语言、季度和集数只筛选已有数据，不重新联网。手动点击“搜索”或按回车时，按输入框关键词及所选语言、季集重新请求选中的来源：“全部”请求所有在线来源，单一来源只请求该来源，“本地”只刷新字幕库。取消旧请求并忽略旧回复；同语言与季集的单来源刷新保留其他来源缓存和错误，一个来源失败不清空其他来源。ASSRT 与 TsukiHime 沿用现有接口，不发送未经确认支持的季集参数，结果按已有资料筛选。
- 输入框右侧复用同一个按钮：开始搜索后显示“暂停”，暂停后显示“继续”，结束后恢复“搜索”，底部不另设暂停按钮。暂停取消未完成的页面请求并保留已完成页、结果和筛选；继续从未完成页接着查询，不重新请求已完成页。暂停状态跨筛选和窗口隐藏保留；修改关键词、来源、语言或季集后显示“搜索”，点击后请求新条件。搜索与暂停缓存包含请求语言和季集，不混用不同条件的结果；“全部”与特别篇第 0 季分别记录。搜索框回车执行该按钮当前的操作。暂停使用任务等待，不轮询。
- ASSRT 官方 `POST /v1/sub/search` 通过表单传递搜索词、分页位置及 `filelist=1`，每页取得 15 条。包内文件信息用于显示资料和区分合集，不请求单文件下载地址，不显示单集选择列表。后台依次取得全部分页，空页或重复页结束请求。请求间隔至少 13 秒，遵守当前用户面板每分钟 5 次的额度；等待配额及联网均异步执行，不轮询。
- 季集均选“全部”时保留来源返回的所有结果，包括合集、特别篇及季度不明确的条目；不使用本地标题、年份或季集规则额外删除搜索结果。首次打开时来源、季度、集数和语言均默认选择“全部”；已确认的当前季度和集数放在各行“全部”右侧供手动选择，电影及季集不明确的视频不猜测集数。切换筛选只作用于已有结果，下次手动搜索才使用新条件。各来源按钮显示对应在线结果，“本地”显示已下载结果，“全部”显示两者。
- 字幕和弹幕搜索框内均提供放大镜与双箭头组成的别名按钮，固定展开当前播放作品的中文简繁、英文、日文及其他已有名称，搜索框为空或改成其他作品时同样如此，不根据输入内容重新匹配别名；选择后只填入输入框，点击“搜索”或按回车才重新搜索。别名按钮复用现有公开作品目录及已匹配资料，缺少英文名时通过已有跨站作品对应关系核对补充，同一窗口共享名称查询；选择别名或修改关键词保留已有季集筛选，改搜其他作品不带入原视频的播放归属信息。手动选择字幕季集后，输入框同步显示标准后缀（例如 `S04E01`），改选时替换，选择“全部”时移除对应部分；选择别名同样保留后缀，列表仍显示原名。普通字幕搜索原样使用可见关键词，不额外查询作品目录、不换词、没有结果也不自动尝试别名；弹幕保留原有自动别名匹配。来源仍可返回其自身关联的其他语言标题。没有结果、请求进度和错误只显示一次，不添加分页按钮或底部来源提示。
- 字幕输入框、来源、季度、集数、语言和结果共用一个纵向滚动列表，保留原生像素滚动与结果虚拟化。搜索前显示当前季集作为候选，默认仍选“全部”；当前季集在各自候选中优先排列，当前集在“全部”季度或当前季度下保留。已选季度和集数作为搜索条件一直显示，不因修改或清空关键词、清空旧结果、完成空结果、搜索失败、暂停继续或切换其他筛选而改变；重新打开窗口同样保留。未选集数从所选语言对应的单集资料、包内字幕文件及本地索引生成，不把另一种语言独有的集数混入。浏览其他集只筛选结果，下载后的自动加载仍对应正在播放的集数。
- 字幕和弹幕列表共用已有 HandyControl 滚动控件，通过 WPF `IScrollInfo` 直接应用输入像素位移；同一布局帧内累加输入，不逐次启动动画或添加缓动延迟。触摸平移使用 WPF 原生处理，系统产生的惯性输入保留其原始幅度。分组列表保留像素滚动、回收虚拟化、前后两页预缓存及主题。
- 搜索进度只显示在左下角；本地结果加入后立即刷新列表状态和条数，中央仅在搜索结束后显示空结果或错误，不覆盖已显示的条目。
- 底部显示结果总数及当前筛选可见条数。标题完整显示来源返回的作品及发布名称；ASSRT 使用 `native_name` 与 `videoname`。左侧显示字幕格式，右侧只用一排显示语言、日期和大小，缺失字段隐藏，不显示评分或其他资料。已下载字幕保存下载时取得的标题、格式及资料，在本地结果中复用。
- 搜索 GET 最多跟随三次同一 HTTPS 主机、端口与接口路径的重定向，禁止把密钥转发至其他地址。POST 不跟随重定向或自动重试。

同一集内返回并重新进入窗口保留搜索结果、关键词、筛选和滚动位置，已开始的请求继续完成；明确点击搜索才刷新。切换视频后结束旧窗口会话。

所有筛选行的“全部”位于最左边。语言按钮只占一行，可横向滚动；“全部”之后依次为简体中文、繁体中文、英语、日语，随后显示当前来源和季度已有的其他语言。搜索前和无结果时仍可选择这四种语言，默认“全部”，手选之后当前选项不会因没有结果而消失。仅能确认中文但不能确认简繁的保留为“中文”，完全无法确认语言的归入“其他”。切换语言只筛选现有结果，下次手动搜索才使用新的语言条件；ASSRT 与 TsukiHime 按返回资料筛选，不发送来源不支持的语言参数。

## 下载与本地复用

- 播放、切换视频、自动搜索及筛选不会自动下载。用户直接点击结果后立即关闭窗口，由播放器继续下载；本地条目点击直接加载。不显示额外下载按钮或可点击的单集文件列表。
- 搜索词只用于请求字幕来源。点击下载后，使用已确认的当前作品名称、别名与作品编号核对所选字幕及其详情；确认属于当前作品后按播放器的规范作品名保存，并核对当前季集自动加载，不以手工输入的英文短词另建作品目录。核对复用本地匹配记录和本次已取得的字幕详情，不额外查询作品目录。
- ASSRT 官方 `POST /v1/sub/detail` 取得原始包的 `filename` 和 `url`，禁止缓存此请求。不读取或请求 `filelist` 的单文件下载地址。ASSRT 剧集只下载来源提供的 ZIP、RAR 或 7z 整包；没有整包或下载失败时不改为逐集下载。电影可下载来源提供的独立字幕文件。
- ameNZB 和 TsukiHime 下载用户选中的单集字幕。TsukiHime 的 XZ 附件解压后保存实际字幕，按接口的 `animetosho` 标记区分外部镜像和本站附件；本站附件要求已缓存，AnimeTosho 镜像附件没有本站缓存字段，不以缺少该字段拒绝下载。保留原始语言匹配及完整文字轨筛选，不用其他语言、强制轨或招牌歌词轨替代。ameNZB 使用公开字幕下载地址。只请求字幕，不请求发布页面所列视频、NZB 或种子资源。当前视频与所选条目的作品、季集不对应时只保存，不加载其他集。
- 解压后的全部可用字幕长期保留，按 `%LOCALAPPDATA%/mpv-AnimeFusion/Subtitles/作品名/第 N 季/来源-条目编号/` 分目录，不添加 Downloads 层。多季合集使用包内目录、文件名的明确季度以及同包作品名与数字后缀分别归档和索引，电影、特别篇、无法确定的条目分别使用“电影”“特别篇”“未分类”；无法确定的文件不用于播放季集匹配。保留原始文件名及包内子目录。
- 原始压缩包在 `作品名/字幕包/Assrt-条目编号/` 只保存一份，不随当前播放季度变化。合集各季共同复用原包和本地文件，搜索中同一来源编号只显示一个本地条目，季度筛选使用实际保存的季度集合。
- 使用 SharpCompress 解压，不执行包内程序。校验路径、大小、条目数量、加密条目及链接，只保存支持的字幕格式，IDX/SUB 成对加载。解压失败保留原包和已保存文件，再次点击复用原包。
- 通过 mpv 原生 `show-text` 和小号 ASS 样式显示下载、解压进度。已知大小按 10% 变化更新；未知大小随读取事件最多每秒更新一次，不轮询。成功加载后立即清除进度，直接显示实际字幕；下载失败只显示“字幕下载失败”，本地加载失败只显示“字幕加载失败”，不显示来源和内部筛选原因。只保存未加载时保留简短提示。切换视频、标题或退出取消旧任务，旧回复不能给新视频加载字幕。
- 使用现有文件名解析器对应当前集和上次选择的语言版本；没有对应集时只保存整包，不加载其他集。每季的 `subtitles.json` 记录已下载文件及选择，不保存密钥或临时下载链接。
- 拖入、粘贴或导入的本地字幕通过 mpv 原生轨道变动写入当前作品的字幕库，保留原文件并复制到库内。同目录可确认属于同套作品的其他集一起保存，当前轨道只使用对应集；已有字幕包内的手动选择只关联选中的字幕及必要的 IDX/SUB 配对。
- 打开作品时将当前集的本地版本加入 mpv 字幕列表，优先使用强制使用的整套版本；选择记录在作品的 `selection.json`，覆盖内封默认轨和播放入口指定的字幕参数。没有强制使用时，明确传入的字幕优先于该季普通记忆。原生 `sub-add ... auto` 添加可切换版本，`cached` 选中已加入的字幕。切换主字幕轨更新普通记忆，保留独立强制使用记录和第二字幕轨中的弹幕。
- 本地字幕行使用大写 `F` 切换强制使用状态，并使用垃圾桶符号删除。删除必须确认，默认仅移除该作品的字幕记录和当前轨；勾选“同时删除本地文件”会清理选中字幕的库内文件、已记录的对应导入原文件和该来源的原始字幕包，保留其他集的解压文件。原文件内容发生变化或仍被其他作品引用时停止并提示。确认期间切换视频会使旧操作失效。
- 本地字幕轨显示完整原始文件名，不附加语言、来源、格式或外挂标记；在线字幕使用真实名称和已有语言，通用 Stream.ass 名称不显示，缺少名称时使用已有语言、格式与轨道编号区分。
- 已保存文件和后续集数优先本地复用，不重新下载。下载地址使用独立、不携带账号头的 HTTP 请求；来源设置变更或视频切换取消搜索，不轮询网络状态。

## 在线字幕名称

客户端只传入 Emby 在线字幕地址时，`SubtitlePlayback` 通过官方 `GET /Items/{Id}/PlaybackInfo` 一次取得全部媒体版本，再按相同服务器、作品编号、媒体源编号和字幕索引读取 `MediaSources/MediaStreams` 的实际 `DisplayTitle` 与 `Language`。沿用本次播放地址中的授权和客户端身份、代理及证书校验选择；凭据不转发至其他来源，也不写入菜单或磁盘。每个播放条目的资料请求只发一次，菜单打开和字幕切换不增加请求。资料返回后通过现有播放器状态属性刷新菜单，切换视频取消旧请求；不请求视频流、不重新下载字幕或改变字幕选择。

来源另有 `Title` 时一并保留，避免 `DisplayTitle` 只有“ASS”时丢掉实际的 SC、TC 等名称。同一作品的不同媒体版本不混用轨道名称或语言。条目列表可能只返回默认媒体版本，不能用它替代播放资料接口。接口定义见 [Emby PlaybackInfo](https://dev.emby.media/reference/RestAPI/MediaInfoService/getItemsByIdPlaybackinfo.html)。

## 内封字幕切换

网络视频使用原生 `demuxer-cache-unselected-subs=yes` 保留未选字幕轨的数据。修改位于 mpv 的解复用缓存中，由 `tools/apply_subtitle_track_cache.py` 应用至固定源码版本，随现有原生构建流程编译。它沿用当前视频输入与读取线程，不启动字幕提取任务或额外视频连接。

切换轨道只调整字幕读取位置，不执行清空音视频队列的刷新跳转。未选字幕按现有播放位置更新缓存游标，继续使用原有前向、后向缓存上限；切换时包含仍有效的重叠字幕事件。缓存范围合并与恢复同时处理未选字幕的重复包。

这个选项保留正常读取中已经取得的字幕，不要求播放前读完整集。仅对字幕来自当前输入的解复用器启用；HLS、DASH 等独立下载的字幕版本不作为内封字幕预读，反向播放沿用原生处理。

## 验证范围

`tests/subtitles/SubtitleChecks.csproj` 使用隔离目录和模拟接口检查缓存、分页、主动刷新、筛选、密钥保留、重定向、整包下载、本地复用、目录校验及 WPF 像素滚动。`NativePlaybackChecks.csproj` 使用生成的本地视频验证原生字幕选择、明确指定的字幕优先级、第二字幕轨保留及加载后清除进度；不操作桌面或请求用户的视频流。

ASSRT 真实搜索及密钥验证需要有效凭据；ameNZB 和 TsukiHime 可单独验证公开搜索及字幕下载。编译成功不等同于联网或桌面触摸板交互已验收。
